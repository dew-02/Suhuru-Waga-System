

# Suhuru Waga System 🌾
**Smart Agriculture Platform – Full MERN Stack**

A comprehensive digital agriculture platform designed to bridge the gap between **farmers, landowners, buyers, government agricultural resources, and modern technology**, providing AI-powered insights, transparent workflows, and efficient communication.

---

## 🚀 Project Overview

Suhuru Waga empowers stakeholders in Sri Lankan agriculture by integrating **five key modules**:

- **AI-Powered Crop Suggestion System 🤖** – Intelligent crop recommendations based on location, soil, goals, and land size.
- **Government Information Management 🏛️** – Digital portal for notices, alerts, PDF forms, and resource sharing.
- **Land Management & Bidding 🏞️** – Transparent system for landowners to list idle land and for farmers to bid.
- **Resource Management 🚜** – Book and manage agricultural resources like tractors, lorries, seeds, and equipment.
- **Order Management 🛒** – Buyers can search crops, place orders, upload payment receipts, and coordinate deliveries with farmers via WhatsApp.

## 🗂️ System Workflow

### Landowners:
- List idle land → Set bidding period → Review highest bidder → Sign digital lease.

### Farmers:
- Browse available lands → Submit bids with cultivation plan → Access AI Crop Suggestions → Track expenses & yield.

### Buyers:
- Register → Search crops → Place orders → Upload payment → Discuss delivery with farmers via WhatsApp.

### Government Officers:
- Publish notices → Broadcast alerts → Share PDFs and video tutorials → Digitally collect forms.

### Resource Providers:
- Add available resources → Manage bookings → Track demand and allocation.

### Admin/System:
- Manage users → Oversee modules → Ensure role-based access control → Maintain system stability.

---

## 📈 Database Structure (Highlights)

**Collections:**
- Users (farmers, buyers, landowners, officers)  
- Lands & Bids  
- Crops & Orders  
- Notices & Resources  

**Relationships:**
- Each bid links buyer + land  
- Each order links buyer + crop + farmer  
- Each notice/resource linked to government officer
